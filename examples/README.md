# Planning demo

`planning-demo.html` is an original, fictional planning document distributed under
the repository's [MIT license](../LICENSE). It uses local CSS, anchor navigation,
tables, checklists and native details elements. It requires no JavaScript,
external resources, accounts or network access.

The first-run seed imports this demo only when `SEED_EXAMPLE=true`. Restarting an
existing installation does not replace any stored plan or revision. Do not put
real customer data, internal plans or credentials in public examples.

Checkboxes and expanded sections in the preview are temporary browser state.
Persist decisions by editing and saving the planning document.
